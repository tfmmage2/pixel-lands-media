# Pixel Land Online – Media

Public media for Instagram @Pixel_Lands_Online. **Media only: no game code, no project files, no secrets.**

- `raw/<YYYY-MM-DD>_<build>/`: clips (.mp4) and pictures (.png/.jpg) each build chat saves when it ships, with a `notes.md` (date, build, one line per file on what's new).
- `reels/<YYYY-MM-DD>_devlogNN.mp4`: finished Reels that were posted.
- `posted.md`: the log of every post, in order.
